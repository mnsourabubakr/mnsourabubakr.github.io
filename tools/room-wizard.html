Room Wizard Tool

A professional room-finish automation workspace that reads room data, detects existing floor finishes, configures single- or multi-layer finish build-ups, and safely creates or updates room-based finish floors with 3D review and conflict handling.

What the tool does

Key capabilities

  • Central room grid for placed and enclosed rooms with number, name, level, area, volume, department, design option, and optional custom Room-parameter columns
  • Create room-based floor finishes from either a single visible material or a custom multi-layer build-up, with reusable Revit floor types generated from the selected layer definition
  • One-click 3D room review with an automatically sized Section Box and optional colorization of Room Wizard-managed finishes
  • Detect existing finish conflicts before modeling; safely resolve supported overlaps automatically, while unsafe, pinned, grouped, structural, or otherwise protected floors remain available for manual review
  • Match one room’s finish setup to other rooms, then copy the setup only or copy and apply it in a controlled batch workflow
  • Search, multi-level sorting, configurable table columns, batch Apply Selected, and optional rooms from loaded linked models for large architectural projects
  • Tracks Room Wizard-owned floors and applies worksharing safety checks so updates target the intended finish elements instead of unrelated model geometry
